# Япония 2026 — GitHub Pages · версия 4

Статический мобильный путеводитель на Next.js/React. Он рассчитан на iPhone, устанавливается как PWA и после подтверждённого сохранения открывает весь внутренний маршрут без сети. Внешние сайты достопримечательностей, Tabelog и карты остаются онлайн-ссылками.

## Архитектура

- `output: "export"`: сервер и база данных не нужны;
- основной контент заранее отрисовывается в HTML;
- главная навигация использует обычные переходы между документами и не зависит от ошибочного статуса сети;
- JavaScript остаётся только у блоков «Сейчас / дальше», локальных отметок, кодов и офлайн-панели;
- после сборки `scripts/generate-pwa-assets.mjs` сканирует `out/`, создаёт версию по хешу содержимого и генерирует точный список офлайн-ресурсов;
- Service Worker удаляет только собственные кэши `japan-2026-*`, сохраняет одну предыдущую версию и подтверждает готовность через двустороннее сообщение;
- коды бронирований не входят в публичные данные и при необходимости вводятся локально на конкретном устройстве.

Шрифт `assets/fonts/NotoSansSC-Regular.ttf` используется только отдельным генератором мобильного PDF и не попадает в опубликованный сайт.

## Локальная проверка

```bash
npm ci
npm run check
npm start
```

Статический экспорт создаётся в `out/`. Для полного браузерного теста PWA:

```bash
npx playwright install chromium
npm run test:offline
```

`npm run check` запускает lint, production-сборку и проверки HTML, внутренних ссылок, офлайн-манифеста, PWA-иконок и отсутствия публичных кодов. `npm run test:offline` сохраняет сайт, отключает сеть и открывает все маршруты; дополнительно проверяет, что кэш соседнего проекта не удалён.

## Публикация

В `Settings → Pages` выберите `Source: GitHub Actions`. Workflow `.github/workflows/pages.yml` автоматически:

1. устанавливает фиксированные зависимости из `package-lock.json`;
2. запускает все проверки и сборку с корректным `basePath`;
3. проверяет все страницы в реальном офлайн-режиме;
4. публикует только каталог `out/`.

Новый push отменяет устаревшую незавершённую сборку. В проекте нет OpenAI Sites, Vinext, Cloudflare, Worker runtime или входа через ChatGPT.

## Контроль на iPhone перед поездкой

1. Открыть сайт в Safari и добавить его на экран «Домой».
2. Открыть PWA и дождаться зелёного статуса «Офлайн-копия готова».
3. Нажать «Проверить и обновить копию».
4. Полностью закрыть приложение, включить авиарежим и открыть его снова.
5. Проверить главную, все дни, подготовку, Китай, гастрономию, транспорт, шопинг и карманную памятку.
