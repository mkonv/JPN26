# Japan 2026 — карта исправлений по аудиту 15.08.2026

**Канонический baseline:** полный 92-пунктовый аудит, предоставленный пользователем 15.08.2026.  
**Правило:** операционные факты (расписание, часы, транспорт, адреса, бронирования) не выдумываются и требуют подтверждения. Для еды действует последующее решение пользователя: свинина — **soft preference**, а не абсолютный запрет; сильные и логистически удобные варианты допустимы с явной пометкой.  
**Единый источник для web/PDF:** `data/trip.json` + `data/travel-enrichment.json`.

Статусы:
- **FIXED / SYNCHRONIZED** — ошибка исправлена и данные синхронизированы.
- **REMOVED / BLOCKED** — ненадёжная рекомендация удалена из активного сценария или запрещена до подтверждения.
- **PENDING VERIFY / NOT CLAIMED** — точная информация не выдумывается; источник должен быть подтверждён ближе к дате.
- **SOFT FOOD POLICY** — блюдо не маркируется как pork-free без проверки, но наличие свинины само по себе не блокирует сильный или удобный вариант.

## Regression checks

`tests/audit-regressions.test.mjs` проверяет критические группы ошибок: Fuji/SmartEX/JR-West/HARUKA, невозможные тайминги и закрытия, Katsura/Hakone, Tokyo/NRT, ресторанные блокировки, China/Amap/shuttle и контраст PDF/web.

## Визуальный контраст

- Web `.decision-trigger`: светлый золотистый фон + тёмно-коричневый текст.
- PDF hero badges: `GOLD_SOFT` + тёмно-коричневый текст.
- 8-значные псевдопрозрачные hex-цвета ReportLab удалены, чтобы избежать неправильной интерпретации цвета.
